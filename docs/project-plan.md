# แผน Mini Project ระบบยืม–คืนอุปกรณ์

## เป้าหมาย

ทำเว็บเล็ก ๆ สำหรับบันทึกอุปกรณ์ ผู้ยืม การยืม และการคืน รองรับอุปกรณ์หลายประเภท
โดยผู้ดูแลระบบหนึ่งคนหรือทีมขนาดเล็ก ข้อมูลเก็บใน SQLite บนเครื่องเดียว

ระบบนี้เน้นให้ใช้ง่ายและค้นข้อมูลย้อนหลังได้ ไม่ได้ออกแบบเป็นระบบระดับองค์กร

## ผู้ใช้

- ผู้ดูแลเป็นคนเพิ่มข้อมูลและทำรายการทั้งหมด
- ผู้ยืมไม่มีบัญชีสำหรับเข้าใช้งาน
- ยังไม่มีระบบเข้าสู่ระบบหรือกำหนดสิทธิ์

## งานหลัก 5 ส่วน

หน้าแรกเป็น Dashboard สำหรับดูจำนวนอุปกรณ์และเปิดงานจัดการคลัง 3 แบบ
ส่วนเมนูงานหลักยังแบ่งตาม 5 ส่วนด้านล่าง

### 1. อุปกรณ์

- สร้างหมวดหมู่แยก เช่น คอมพิวเตอร์ วิทยาศาสตร์ เครื่องมือช่าง หรืออุปกรณ์ทั่วไป
- เพิ่มอุปกรณ์โดยระบุชื่อ หมวดหมู่ รหัสที่ไม่ซ้ำ และตำแหน่งเก็บ
- บันทึกตำแหน่งที่เก็บ
- ดูสถานะ: พร้อมใช้, ถูกยืม, ส่งซ่อม หรือเลิกใช้
- ค้นหาจากรหัสหรือชื่อ

### 2. คนในระบบ

- เพิ่มผู้บันทึกรายการ
- เพิ่มผู้ยืม
- ค้นหาจากรหัสหรือชื่อ

### 3. ทำรายการยืม

- เลือกผู้ยืม ผู้บันทึก และอุปกรณ์
- ระบุวันที่ยืม วันที่ต้องคืน และรายละเอียดสั้น ๆ
- ค่าเริ่มต้นวันคืนคือ 3 วัน
- ยืมได้เฉพาะอุปกรณ์ที่พร้อมใช้

### 4. คืนอุปกรณ์

- เลือกรายการยืมที่ยังไม่จบ
- เลือกอุปกรณ์ที่นำมาคืน
- ระบุว่าคืนปกติหรือต้องส่งซ่อม
- บันทึกผู้รับคืน ตำแหน่งที่เก็บ และหมายเหตุ
- คืนบางส่วนได้ และปิดรายการเมื่อคืนครบ

### 5. ประวัติ

- ดูการเพิ่ม ยืม คืน ย้ายตำแหน่ง และเปลี่ยนสถานะอุปกรณ์
- ค้นหาจากผู้ยืม ชื่ออุปกรณ์ รหัสอุปกรณ์ หรือวันที่

## กติกาที่จำเป็น

1. รหัสอุปกรณ์แต่ละชิ้นห้ามซ้ำ
2. ยืมได้เฉพาะอุปกรณ์ที่มีสถานะพร้อมใช้
3. อุปกรณ์หนึ่งชิ้นห้ามอยู่ในรายการยืมที่ยังไม่จบมากกว่าหนึ่งรายการ
4. เมื่อคืนปกติ อุปกรณ์กลับเป็นพร้อมใช้
5. เมื่อส่งซ่อม อุปกรณ์ยังยืมต่อไม่ได้จนกว่าจะบันทึกว่าซ่อมเสร็จ
6. ไม่ลบรายการยืมและคืน เพื่อให้ตรวจสอบย้อนหลังได้
7. ระบบใช้วันที่และเวลาตาม `Asia/Bangkok`

## ไม่ทำใน Mini Project

- ระบบเข้าสู่ระบบและกำหนดสิทธิ์
- การอนุมัติหลายขั้นตอน
- กระบวนการชดใช้ของสูญหาย
- อุปกรณ์ทดแทนและการประเมินราคา
- QR/Barcode และ GPS
- LINE หรืออีเมลแจ้งเตือน
- Dashboard, PDF, Excel และรายงานขั้นสูง
- รองรับหลายสาขาหรือผู้ใช้จำนวนมากพร้อมกัน
- Cloud deployment และ PostgreSQL

โค้ดฐานข้อมูลบางส่วนอาจรองรับงานเหล่านี้อยู่แล้ว แต่จะไม่แสดงเป็นงานหลักในหน้าจอ
เพื่อให้ mini project ใช้งานและดูแลได้ง่าย

หากฐานข้อมูลเดิมมีอุปกรณ์สถานะ `แจ้งหาย` ผู้ดูแลยังปิดข้อมูลเดิมได้จากหน้า
อุปกรณ์ โดยเลือกว่าพบอุปกรณ์แล้วหรือปิดรายการเดิม ฟังก์ชันนี้มีไว้รักษาข้อมูลเดิม
และไม่ใช่กระบวนการชดใช้

## ลำดับตรวจรับงาน

### ขั้นที่ 1 — ตรวจเส้นทางหลัก

- เพิ่มอุปกรณ์และคนในระบบ
- ยืมและคืนด้วยข้อมูล SQLite จริง
- ตรวจข้อความผิดพลาดและสถานะหลังบันทึก

### ขั้นที่ 2 — ตรวจการใช้งาน

- ทดสอบหน้าจอคอมพิวเตอร์และมือถือ
- ทดสอบข้อมูลว่าง รหัสซ้ำ ยืมซ้ำ และคืนบางส่วน
- ทดลองปิดแล้วเปิด container ใหม่เพื่อยืนยันว่าข้อมูลยังอยู่

### ขั้นที่ 3 — ส่งมอบ

- เตรียมข้อมูลตัวอย่างสำหรับสาธิต
- ตรวจ README และคำสั่ง Docker
- เก็บเฉพาะ bug ที่กระทบงานหลัก

## เกณฑ์ว่าโครงการเสร็จ

- ผู้ใช้เพิ่มอุปกรณ์ ผู้บันทึก และผู้ยืมได้
- ทำรายการยืมและคืนได้โดยสถานะอุปกรณ์ถูกต้อง
- ค้นหารายการและดูประวัติย้อนหลังได้
- ข้อมูลยังอยู่หลังเปิดระบบใหม่
- หน้าจอใช้งานได้ทั้งคอมพิวเตอร์และมือถือ
- ชุดทดสอบทั้งหมดผ่าน
