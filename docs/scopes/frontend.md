# งาน Frontend สำหรับ Mini Project

## เป้าหมาย

ทำหน้าจอ Flet ให้เจ้าหน้าที่ทำงานหลักได้เร็ว โดยเริ่มจากคิวงานและค้นหาด้วยชื่อ/รหัส
แทนการไล่ผ่านฟอร์มหลายชั้น

## งานที่ต้องทำ

### งานวันนี้

- แสดงจำนวนพร้อมใช้ กำลังถูกยืม ต้องคืนวันนี้ และเกินกำหนด
- แสดงคิวรายการที่ต้องจัดการก่อน พร้อมปุ่ม “ยืมอุปกรณ์” และ “รับคืน”
- แสดงงานรอซ่อม/แจ้งหายเป็น feedback ที่มองเห็นได้

### 1. อุปกรณ์

- แสดงรายการแบบตาราง พร้อมค้นหาและตัวกรองสถานะ
- ใช้ค้นหาและตรวจสถานะเป็นหลัก; ผู้ดูแลเพิ่มชิ้นใหม่หรือเปลี่ยนสถานะ/จุดเก็บได้ใน dialog

### 2. คนในระบบ

- แสดงผู้บันทึกรายการและผู้ยืมแบบตาราง
- เพิ่มและค้นหาผู้บันทึกรายการ โดยเปิดฟอร์มเพิ่มหรือแก้ไขใน dialog
- เพิ่มและค้นหาผู้ยืม โดยเปิดฟอร์มเพิ่มหรือแก้ไขใน dialog

### 3. ยืมและคืน

- เลือกข้อมูลจากรายการที่มีอยู่จริง
- ยืมหลายชิ้นในรายการเดียวด้วยหน้าเดียว และยืนยันด้วยปุ่มเดียว
- แสดงคิวรายการที่รอคืน โดยเลือกคืนทั้งหมดให้อัตโนมัติ
- เลือกคืนทั้งหมดหรือบางส่วน พร้อมผลลัพธ์พร้อมใช้/ส่งซ่อม/แจ้งหาย
- ปรับฟอร์มให้เรียงแนวตั้งบนมือถือ

### 4. ประวัติ

- แสดงเหตุการณ์แบบตาราง เรียงจากใหม่ไปเก่า
- ตัวกรองต้องค้นข้อมูลได้จริง

## ยังไม่ทำในรอบนี้

- approval หลายขั้นและกราฟ/รายงานขั้นสูง
- หน้าชดใช้ของสูญหาย
- QR scanner บังคับ และ export report
- animation หรือ component library เพิ่มเติม

## เสร็จเมื่อ

- คิวงานและเมนูงานหลักทำงานครบตามสิทธิ์
- ไม่มีปุ่มที่กดแล้วไม่เกิดผล
- ข้อความใช้ภาษาไทยที่เข้าใจง่าย
- ใช้งานได้ที่ความกว้าง desktop และ mobile
- UI tests ผ่าน

ข้อมูลสถานะ `แจ้งหาย` จากฐานข้อมูลเวอร์ชันก่อนจัดการแบบย่อในหน้าอุปกรณ์เท่านั้น
โดยเลือก “พบอุปกรณ์ที่เคยแจ้งหาย” หรือ “ปิดข้อมูลแจ้งหายเดิม”
