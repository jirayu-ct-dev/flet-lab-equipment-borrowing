# งาน Backend สำหรับ Mini Project

## เป้าหมาย

เก็บข้อมูลด้วย SQLite และดูแลสถานะอุปกรณ์ให้ถูกต้อง โดยหน้าจอเรียกใช้งานผ่าน service

## งานที่ต้องทำ

### 1. ข้อมูลพื้นฐาน

- หมวดหมู่แยก และอุปกรณ์ที่อ้างอิงหมวดหมู่
- ตำแหน่งเก็บ
- ผู้บันทึกรายการและผู้ยืม
- ป้องกันรหัสซ้ำ

### 2. การยืม

- สร้างและยืนยันรายการยืมใน transaction เดียว
- ตรวจว่าอุปกรณ์พร้อมใช้ก่อนยืนยัน
- ป้องกันอุปกรณ์ชิ้นเดียวถูกยืมซ้ำ

### 3. การคืน

- คืนทั้งหมดหรือบางส่วน
- เปลี่ยนสถานะเป็นพร้อมใช้หรือส่งซ่อม
- ปิดรายการอัตโนมัติเมื่อคืนครบ

### 4. การค้นหาและประวัติ

- ค้นหารายการที่กำลังยืม ใกล้ครบกำหนด และเกินกำหนด
- ส่งข้อมูลประวัติให้หน้าจอแสดงผล
- ใช้วันที่ตาม `Asia/Bangkok`

## ไม่ต้องเพิ่ม

- API server แยกจาก Flet
- Login, role และ SSO
- ระบบอนุมัติหรือ workflow หลายขั้น
- PostgreSQL, cloud storage และระบบหลายสาขา
- รายงานหรือระบบแจ้งเตือน

โครงสร้างเดิมสำหรับกรณีสูญหายและบันทึกการแก้ไขยังเก็บไว้เพื่อไม่ให้ migration เดิมเสีย
และมี service แบบย่อให้ปิดข้อมูลแจ้งหายเดิมได้ แต่ไม่ต้องขยายเป็นขั้นตอนอนุมัติหรือชดใช้

## เสร็จเมื่อ

- เส้นทางเพิ่มอุปกรณ์ → ยืม → คืน → ดูประวัติทำงานกับ SQLite จริง
- การบันทึกที่ล้มเหลวไม่ทิ้งข้อมูลค้างครึ่งหนึ่ง
- ข้อมูลยังอยู่หลังเริ่มโปรแกรมใหม่
- Integration tests ผ่าน
