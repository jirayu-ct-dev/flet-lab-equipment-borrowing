# การจัดการคนในระบบ

หน้า `คนในระบบ` เป็นจุดเริ่มต้นสำหรับผู้ดูแล โดยรวมข้อมูลเจ้าหน้าที่ ผู้ยืม และบัญชีเข้าใช้ไว้ในรายการเดียว

## งานประจำ

1. ค้นหาด้วยชื่อ รหัส อีเมล หรือคำว่า `LINE`
2. ใช้ตัวกรอง `ประเภท` และ `สถานะ` เมื่อต้องการหากลุ่มใดกลุ่มหนึ่ง
3. กด `เพิ่มบุคคล` เพื่อสร้างข้อมูลเจ้าหน้าที่หรือผู้ยืม รหัสจะถูกเสนอให้อัตโนมัติและยังแก้ไขได้ก่อนบันทึก
4. หากอีเมลตรงกับบัญชีเข้าใช้ที่ยังไม่ผูก ระบบจะผูกบัญชีให้อัตโนมัติ
5. กด `แก้ไข` เพื่อแก้ข้อมูลบุคคลและสถานะของข้อมูล
6. กด `จัดการบัญชี` เพื่อเปลี่ยนสิทธิ์ สถานะบัญชี ผูกเจ้าหน้าที่/ผู้ยืม หรือรีเซ็ตรหัสผ่าน

## ความหมายของสถานะ

- `ใช้งาน`: ข้อมูลหรือบัญชีใช้งานได้
- `ปิดใช้งาน`: เก็บประวัติเดิมไว้ แต่ไม่ควรใช้ทำรายการใหม่หรือเข้าสู่ระบบ
- `ยังไม่มีบัญชี`: มีข้อมูลบุคคลแล้ว แต่ยังไม่มีบัญชีเข้าใช้ที่ผูกไว้
- `บัญชีที่ยังไม่ผูกบุคคล`: พบการเข้าสู่ระบบแล้ว แต่ยังไม่เชื่อมกับเจ้าหน้าที่หรือผู้ยืม

## แนวทางผูก LINE

เมื่อผู้ใช้ล็อกอินด้วย LINE ครั้งแรก บัญชีอาจแสดงเป็น `บัญชีที่ยังไม่ผูกบุคคล` ให้ผู้ดูแลเปิด `จัดการบัญชี` แล้วเลือกผู้ยืมที่ตรงกับตัวจริง จากนั้นบันทึกการผูกบัญชี

ห้ามใช้ LINE ID แทนรหัสผู้ยืม และห้ามลบบุคคลที่มีประวัติการยืม ให้เปลี่ยนเป็น `ปิดใช้งาน` แทน
